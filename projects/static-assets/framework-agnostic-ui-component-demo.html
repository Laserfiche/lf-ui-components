Framework-agnostic UI components

Every component below is created with document.createElement and configured through properties on the element. The tags a host may create are the documented entry points: lf-field-container, lf-field-template-container, lf-field-adhoc-container, lf-repository-browser, lf-breadcrumbs, lf-toolbar, lf-tags, lf-login, lf-checklist and lf-user-feedback. Other registered tags are internal; the library renders them itself under lfint- names and they are not part of the supported surface.

lf-field-container

Composite component. Configured with initAsync after the element is in the DOM.

lf-repository-browser

Composite component; renders its own breadcrumbs and projects the toolbar you pass in.

lf-tags

Leaf component. tagsService and initialTags are read once, when the element first renders, so they must be set before the element is appended.

lf-user-feedback

Leaf component. Configured by setting properties after the element is appended; the button stays disabled until both user_id and account_id are set. Submitting sends the feedback as a tracking event, so the demo uses test IDs.
