Framework-agnostic UI components

Every component below is created with document.createElement and configured through properties on the element. The tags a host may create are the documented entry points: lf-field-container, lf-field-template-container, lf-field-adhoc-container, lf-repository-browser, lf-selection-list-component, lf-breadcrumbs, lf-toolbar, lf-tags, lf-login, lf-checklist and lf-user-feedback. Other registered tags are internal; the library renders them itself under lfint- names and they are not part of the supported surface.

lf-field-container

Composite component. Configured with initAsync after the element is in the DOM.

lf-repository-browser

Composite component; renders its own breadcrumbs and projects the toolbar you pass in.

lf-tags

Leaf component. Configured by setting properties before the element is appended.
