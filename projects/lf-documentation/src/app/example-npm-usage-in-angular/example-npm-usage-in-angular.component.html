Using UI Components from NPM Package in Angular

This is an alternative to using the CDN that is only possible in Angular.

Example: lf-checklist

In the example below, both the implementation and types are provided via @laserfiche/lf-ui-components/lf-checklist.

  1. Follow these steps to get started.

  2. Import the standalone component directly in your component's imports array. No NgModules are needed — all components are standalone and zoneless.

    import { LfChecklistComponent } from '@laserfiche/lf-ui-components/lf-checklist';

@Component({
  selector: 'app-attachments',
  standalone: true,
  imports: [LfChecklistComponent],
  templateUrl: './attachments.component.html',
})

  3. Import the style sheet from the npm package by adding this line in styles.css in your angular application. 

    @import '~@laserfiche/lf-ui-components/cdn/lf-laserfiche-lite.css';
@import '~@laserfiche/lf-ui-components/cdn/indigo-pink.css';
  4. Use lf-checklist. 
    import { AfterViewInit, Component, ViewChild } from '@angular/core';
// we can directly import types and components from the NPM package
import { Checklist, LfChecklistComponent, LfChecklistService } from '@laserfiche/lf-ui-components/lf-checklist';

@Component({
  selector: 'app-attachments',
  standalone: true,
  imports: [LfChecklistComponent],
  templateUrl:  './attachments.component.html',
  styleUrls: ['./attachments.component.css'],
})

export class ExampleApp implements AfterViewInit {

  // allows access to the LfChecklistComponent in the html above, available starting in ngAfterViewInit hook
  @ViewChild('myChecklist') checklist!: LfChecklistComponent;

  // type Checklist is the type imported from the NPM package
  currentChecklist: Checklist[];

  // events for the components are received as EventEmitters
  onChecklistChanged(checklist: Checklist) {
    // data is passed directly
  }

  ngAfterViewInit() {
    // the component's view is initialized after ngAfterViewInit
    this.checklist.initAsync(...)
  }
}

Secondary Entry Points

@laserfiche/lf-ui-components has several secondary entry points, allowing you to only import the components needed in your project.

  • @laserfiche/lf-ui-components/lf-checklist contains LfChecklistComponent to use <lf-checklist-component>.
  • @laserfiche/lf-ui-components/lf-login contains LfLoginComponent to use <lf-login-component>.
  • @laserfiche/lf-ui-components/lf-metadata contains LfFieldContainerComponent, LfFieldAdhocContainerComponent, and LfFieldTemplateContainerComponent to use <lf-field-container-component>, <lf-field-adhoc-container-component>, and <lf-field-template-container-component>.
  • @laserfiche/lf-ui-components/lf-user-feedback contains LfUserFeedbackComponent to use <lf-user-feedback-component>.
  • @laserfiche/lf-ui-components/lf-repository-browser contains LfRepositoryBrowserComponent to use <lf-repository-browser-component>.
