Migrating from Modules to Standalone Components

Starting with the Angular 21 version, all Laserfiche UI Components are standalone and zoneless. NgModules (e.g. LfChecklistModule, LfRepositoryBrowserModule) have been removed. Components are now imported directly into other standalone components.

Overview of Changes

  • No more NgModules: LfChecklistModule, LfLoginModule, LfMetadataModule, LfUserFeedbackModule, and LfRepositoryBrowserModule have been removed.
  • Standalone components: Import components directly (e.g. LfChecklistComponent) into your standalone component's imports array.
  • Zoneless: Laserfiche components no longer depend on zone.js.

Step-by-Step Migration

  1. Remove module imports.

    In your app.module.ts (or any NgModule), remove the Laserfiche module imports: 

    // BEFORE (remove these)
import { LfChecklistModule } from '@laserfiche/lf-ui-components/lf-checklist';
import { LfRepositoryBrowserModule } from '@laserfiche/lf-ui-components/lf-repository-browser';
  2. Make your components standalone.

    Add standalone: true to each component that uses Laserfiche UI Components (if not already standalone).

  3. Import the standalone component directly.

    In each component that uses a Laserfiche component, add it to the imports array: 

    // AFTER
import { LfChecklistComponent } from '@laserfiche/lf-ui-components/lf-checklist';

@Component({
  selector: 'app-my-component',
  standalone: true,
  imports: [LfChecklistComponent],
  templateUrl: './my-component.component.html',
})
export class MyComponent { }
  4. Update ViewChild references.

    You no longer need ElementRef wrappers. Reference the component type directly: 

    // BEFORE
@ViewChild('myChecklist') checklist!: ElementRef<LfChecklistComponent>;
this.checklist.nativeElement.initAsync(...);

// AFTER
@ViewChild('myChecklist') checklist!: LfChecklistComponent;
this.checklist.initAsync(...);
  5. Remove app.module.ts if fully standalone.

    If all your components are standalone, replace your root NgModule with bootstrapApplication(): 

    // main.ts
import { bootstrapApplication } from '@angular/platform-browser';
import { provideZonelessChangeDetection } from '@angular/core';
import { provideRouter } from '@angular/router';
import { AppComponent } from './app/app.component';

bootstrapApplication(AppComponent, {
  providers: [
    provideZonelessChangeDetection(),
    provideRouter(routes),
  ],
});

Going Zoneless

Laserfiche UI Components no longer depend on zone.js. To adopt zoneless change detection in your app:

  1. Replace provideZoneChangeDetection() with provideZonelessChangeDetection() in your application config or bootstrap call.
  2. Remove zone.js from your polyfills in angular.json (if present).
  3. Uninstall zone.js if no other dependency requires it: 
    npm uninstall zone.js

Note: Going zoneless in your own app is optional. The Laserfiche UI Components work correctly whether your app uses zone.js or not.

Before & After Examples

Before: Module-based (old)

// app.module.ts
import { NgModule } from '@angular/core';
import { LfChecklistModule } from '@laserfiche/lf-ui-components/lf-checklist';

@NgModule({
  declarations: [AppComponent, MyComponent],
  imports: [BrowserModule, LfChecklistModule],
  bootstrap: [AppComponent],
})
export class AppModule { }

// my-component.component.ts
@Component({
  selector: 'app-my-component',
  template: '<lf-checklist #myChecklist></lf-checklist>',
})
export class MyComponent {
  @ViewChild('myChecklist') checklist!: ElementRef<LfChecklistComponent>;

  ngAfterViewInit() {
    this.checklist.nativeElement.initAsync(...);
  }
}

After: Standalone (new)

// main.ts
import { bootstrapApplication } from '@angular/platform-browser';
import { provideZonelessChangeDetection } from '@angular/core';
import { AppComponent } from './app/app.component';

bootstrapApplication(AppComponent, {
  providers: [provideZonelessChangeDetection()],
});

// my-component.component.ts
import { LfChecklistComponent } from '@laserfiche/lf-ui-components/lf-checklist';

@Component({
  selector: 'app-my-component',
  standalone: true,
  imports: [LfChecklistComponent],
  template: '<lf-checklist #myChecklist></lf-checklist>',
})
export class MyComponent {
  @ViewChild('myChecklist') checklist!: LfChecklistComponent;

  ngAfterViewInit() {
    this.checklist.initAsync(...);
  }
}
