Using UI Components with any HTML framework

Example: lf-tags

In the example below, the implementation comes from the CDN.

  1. Import the UI components and CSS in your pages:

    • Follow these steps to import from CDN
    • Use npm to install the package and include the files at build time. See laserfiche-sharepoint-integration for an example implementation.

  2. Add the CDN script to the <head> of your HTML file.

    <script src="lf-ui-components.js" defer></script>

  3. In the .js file (e.g.: app.js),

    const tags = document.createElement('lf-tags'); // create element before connecting to DOM

tags.tagsService = tagsServiceObject; // required — must be set before appending
tags.initialTags = ['Reviewed']; // optional — array of tag displayName values to pre-select; must be set before the element is inserted into the DOM

document.getElementById('container').appendChild(tags);

function onSelectedTagsChanged(event) {
  const selectedTags = event.detail; // LfTagDefinition[] — event data is in the detail property
}

// listen for the selectedTagsChanged custom event
tags.addEventListener('selectedTagsChanged', onSelectedTagsChanged);

  4. Add the .js script to index.html

    <script src="./app.js" defer></script>
