Using UI Components in a Framework-Agnostic Way

Which tags you can create

The CDN bundle registers a custom element for each of the documented components. These are the tags a host is meant to create:

  • lf-field-container, lf-field-template-container, lf-field-adhoc-container
  • lf-repository-browser, lf-breadcrumbs, lf-toolbar
  • lf-tags, lf-login, lf-checklist, lf-user-feedback

Other registered tags are internal building blocks. The library renders them itself under lfint- selectors, and they are not part of the supported surface — do not create them directly.

lf-field-container and lf-repository-browser are composite: they render other components inside their own view, and they are what most integrations embed. The live demo at the end of this page shows both, alongside the simpler leaf component taught below, and self-checks that each view rendered exactly once.

Simplest example: lf-tags

The steps below show how to use lf-tags, a leaf component, in a plain HTML file without any framework. A live demo is shown at the end.

  1. Import the UI components and CSS in your pages:

    • Option 1: Follow these steps to import from a CDN
    • Option 2: Use npm to install @laserfiche/lf-ui-components and copy the files from ./node_modules/@laserfiche/lf-ui-components/cdn to your distribution folder as a build step. See laserfiche-sharepoint-integration for an example using gulp.

  2. Add the script and CSS to the <head> of your HTML file:

    <script src="lf-ui-components.js" defer></script>
<link rel="stylesheet" href="indigo-pink.css">
<link rel="stylesheet" href="lf-laserfiche-lite.css">

  3. Initialize the UI component in a <script> block in your HTML file:

      function initLfTagsComponent() {
  const tagsElement = document.createElement('lf-tags'); // create element before connecting to DOM

  tagsElement.tagsService = tagsService; // required — must be set before appending
  tagsElement.initialTags = ['Reviewed']; // optional — pre-select by displayName; must be set before appending

  tagsElement.addEventListener('selectedTagsChanged', function(event) {
    const selectedTags = event.detail; // LfTagDefinition[] — event data is in the detail property
  });

  document.getElementById('container').appendChild(tagsElement);
}

customElements.whenDefined('lf-tags').then(initLfTagsComponent); // wait for the element to be defined before creating and appending it
