Using UI Components in a Framework-Agnostic Way

Example: lf-tags

The steps below show how to use lf-tags in a plain HTML file without any framework. Load lf-ui-components.js with a defer script tag, then use customElements.whenDefined to wait for the element to be registered before creating and appending it. A complete working example is shown at the end.

  1. Import the UI components and CSS in your pages:

    • Option 1: Follow these steps to import from a CDN
    • Option 2: Use npm to install the package and include the files at build time. See laserfiche-sharepoint-integration for an example implementation.

  2. Initialize the UI component in a <script> block in your HTML file:

      function appendTags() {
  const tagsElement = document.createElement('lf-tags'); // create element before connecting to DOM

  tagsElement.tagsService = tagsService; // required — must be set before appending
  tagsElement.initialTags = ['Reviewed']; // optional — pre-select by displayName; must be set before appending

  tagsElement.addEventListener('selectedTagsChanged', function(event) {
    const selectedTags = event.detail; // LfTagDefinition[] — event data is in the detail property
  });

  document.getElementById('container').appendChild(tagsElement);
}

customElements.whenDefined('lf-tags').then(appendTags);

  3. Complete example — framework-agnostic-ui-component-demo.html:

    {{ demoFileContent() }}
