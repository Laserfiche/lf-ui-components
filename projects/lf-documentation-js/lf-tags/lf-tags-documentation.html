lf-tags

Web Component for selecting and managing tags with an autocomplete input and chip display.

Quick Start

Add the CDN bundle to your page, then place the element in your HTML:

<script src="lf-ui-components.js" defer></script>
// Configure the element before inserting it into the DOM const tags = document.createElement('lf-tags'); tags.tagsService = { getTagDefinitions() { return Promise.resolve([ { id: 1, name: 'Confidential', displayName: 'Confidential', description: 'Contains sensitive information', isSecure: true }, { id: 2, name: 'Reviewed', displayName: 'Reviewed', description: 'Document has been reviewed', isSecure: false }, ]); } }; tags.initialTags = ['Reviewed']; document.getElementById('container').appendChild(tags); // Listen for selection changes tags.addEventListener('selectedTagsChanged', (event) => { console.log(event.detail); // LfTagDefinition[] });

API Reference

Properties

PropertyTypeDescription
tagsService LfTagsService Required. Object implementing getTagDefinitions(): Promise<LfTagDefinition[]>. Must be set before the element is inserted into the DOM.
initialTags string[] Optional. Array of tag displayName values to pre-select on initialization. Must be set before the element is inserted into the DOM.

Events

EventDetail typeDescription
selectedTagsChanged LfTagDefinition[] Fired whenever the set of selected tags changes. Access data via event.detail.

Interfaces

LfTagsService

interface LfTagDefinition { id: number; name: string; displayName: string; description?: string; isSecure: boolean; }
